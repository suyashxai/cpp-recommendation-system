About This Project

ML-Based Crop Recommendation System — Internship Project

🌾 What is Crop Recommendation?

Selecting the right crop is one of the most important decisions a farmer makes each season. Traditional methods rely on experience and basic soil testing, which can miss the complex interactions between multiple soil and environmental factors.

Machine learning can analyse historical agricultural data to identify patterns that link soil nutrient composition, pH, temperature, humidity, and rainfall to specific crop suitability. This system applies that approach to provide data-driven recommendations for 22 crop types.

✨ Features

  • ✅ Machine learning–based crop recommendation (Random Forest)
  • ✅ Seven agricultural input parameters
  • ✅ Model confidence score with probability breakdown
  • ✅ Prediction history stored in SQLite
  • ✅ Dashboard with live statistics
  • ✅ Responsive, mobile-friendly UI
  • ✅ REST API for programmatic access
  • ✅ Input validation and error handling
  • ✅ Model evaluation across four algorithms

⚠ Disclaimer

This system is an academic/internship project built for learning purposes. Recommendations are based on patterns found in a publicly available dataset and should not be used as the sole basis for real agricultural decisions. Always consult a qualified agronomist or agricultural expert.

📂 Dataset

This project uses the Crop Recommendation Dataset available on Kaggle ( kaggle.com/datasets/atharvaingle/crop-recommendation-dataset). The dataset contains 2,200 samples covering 22 crop types with seven numerical features.
